# Company Or Trust UAT Script

Date:
Tester:

## Steps

1. Open `/apply`.
2. Select service.
3. Complete identity + address + consent.
4. Select ownership `Company or trust`.
5. Enter company/trust details:
   - legal name
   - CIPC/BRNC/registration number
   - representative name
   - representative capacity
6. Upload vehicle + required docs including supporting company docs.
7. Sign mandate and submit.
8. Upload EFT proof on submitted page.
9. In `/admin`, confirm EFT and review checklist.
10. Verify entity fields are visible in Selected Review.
11. Accept/reject docs; confirm approval remains blocked until all required docs accepted.

## Expected

- Supporting docs saved and visible.
- Entity details persisted and displayed.
- Checklist reflects entity details completeness.
- Approval gate enforces company/trust required docs.
