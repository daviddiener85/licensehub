# Deceased Estate UAT Script

Date:

## Steps

1. Open `/apply`.
2. Select service.
3. Complete identity + address + consent.
4. Select ownership `Deceased estate`.
5. Enter estate details:
   - estate name/reference
   - executor/letter reference
   - representative name
   - representative capacity
6. Upload docs (ID, death certificate, executor authority, licence disk, proof of address).
7. Sign mandate and submit.
8. Upload EFT proof on submitted page.
9. In `/admin`, confirm EFT and review checklist.
10. Accept/reject docs and verify gate behavior before approve.

## Expected

- Estate supporting docs saved and reviewable.
- Estate details visible on admin selected review.
- Approval blocked until estate required docs are accepted.
