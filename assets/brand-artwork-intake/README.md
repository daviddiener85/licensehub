# License Hub Brand Artwork Intake

Save the final artwork files in this folder using these exact names.

## Required

- `logo-main.svg`
  - Main full-colour logo, transparent background.

- `logo-main-light.svg`
  - White/light logo for dark backgrounds, transparent background.

- `logo-horizontal.svg`
  - Horizontal logo lockup with the brand name.

- `logo-mark.svg`
  - Icon-only TLH mark, no small wording.

- `social-preview.png`
  - 1200 x 630 PNG for WhatsApp, Facebook, LinkedIn, and link previews.

- `favicon-source.png`
  - 1024 x 1024 PNG source for generating the browser favicon.

## Recommended

- `apple-touch-icon.png`
  - 180 x 180 PNG for iPhone/iPad home-screen previews.

- `app-icon-192.png`
  - 192 x 192 PNG for Android/PWA icons.

- `app-icon-512.png`
  - 512 x 512 PNG for Android/PWA icons.

- `hero-artwork.png`
  - Recommended 2400 x 1400 PNG for a future landing-page hero or banner.

## Notes

- Prefer SVG for logos whenever possible.
- Keep logo files on transparent backgrounds.
- Avoid tiny text in icon-only files.
- Use `The License Hub` or `License Hub` consistently, depending on the final brand decision.
